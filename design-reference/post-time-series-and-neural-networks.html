Classical models forecast a number. DeepAR forecasts a distribution. This post follows the path from one to the other.

From autoregression to recurrent networks

The simplest useful model of a time series says that today looks like a weighted sum of the last few days, plus noise. That is the autoregressive model of order p:

yt = c + p∑i=1 φi yt−i + εt
(1)

Here φi are the weights we estimate and εt is white noise. The model is linear and its memory is exactly p steps long. A recurrent network keeps the same idea, the past predicts the future, but replaces the fixed window with a hidden state that it learns to update.

Predicting a distribution

DeepAR feeds the previous value and the current covariates into an LSTM, and instead of predicting yt directly, it predicts the parameters θt of a likelihood:

ht = LSTM(ht−1, yt−1, xt),    θt = g(ht),    yt ∼ p(y | θt)
(2)

Training maximizes the log-likelihood of the observed values over all series and time steps:

ℒ = ∑t log p(yt | θt)
(3)

What changes in practice

Because every step ends in a distribution, sampling many paths forward gives quantiles for free. The forecast is no longer a line but a fan that widens as the horizon grows.
